# US-05 — Éviter les faux positifs visuels

En tant qu'utilisateur, je veux que les options sélectionnées soient
visuellement distinctes, afin de comprendre rapidement quels critères
participent au filtre final.

Critères d'acceptation :
- les options cochées sont mises en évidence ;
- l'aperçu est lisible et contrasté ;
- les messages d'erreur ou de confirmation sont visibles dans le panneau.
