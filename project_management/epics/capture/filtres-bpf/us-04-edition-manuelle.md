# US-04 — Modifier manuellement le filtre

En tant qu'utilisateur avancé, je veux pouvoir écrire directement une
expression BPF, afin de couvrir des cas non exposés par les contrôles
rapides.

Critères d'acceptation :
- la saisie manuelle est conservée ;
- l'interface signale clairement que le mode manuel est actif ;
- un bouton permet de reprendre la génération automatique depuis les
  contrôles.
